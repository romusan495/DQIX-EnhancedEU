DQIX Enhanced EU v38: create companions at Patty's on one screen, two new cheats, cleaner modern windows.

**What's new since v37**
- **Patty's Recruit a Friend on one screen**: creating a companion at the Quester's Rest now uses the same pop-ups as the start of the game, with the character beside them, and the name can be typed with the keyboard (Modern > Type the character's name with the keyboard). Patty's last question ("Add this character to your character list?") pops up with Yes / No over its text.
- **Cheats > Monsters: HP to 0 in battles, any hit finishes them**: it now works by itself in battles, no need to hold B+Start.
- **Cheats > Monsters: always drop their item (the rare one first)**: off by default, like every cheat.

**Fixed since v37**
- Modern windows: the line under a window's title is grey like the frame instead of white, and no stray pixels show where two windows touch (Misc. and its description).

Thanks to Tsu for these changes.

**How to install**: download *Source code (zip)* below, unzip it and double-click `Install Dragon Quest IX.bat`, then choose your own ROM (USA or European). **Already on v31.x or later?** The game offers the update when it starts (or Help > Check for updates): your saves and settings are kept.

**Not included, on purpose**: no ROM, no game executable and no data from the game. Everything is built on your PC from the ROM you own.

**Playing with friends**: everyone needs the same version, so all of you update to v38.
