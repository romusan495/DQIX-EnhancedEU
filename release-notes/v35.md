DQIX Enhanced EU v35: see how far the HD textures are.

**What's new since v34**
- **HD textures progress bar**: while `textures-hd` makes HD textures in the background, a small bar at the big screen's bottom left shows how far it is. When it is done, "HD textures ready (N new)" shows for a few seconds and the new textures are loaded right away, no restart needed. The bar and the message are in the five languages.
- **It goes on where it stopped**: the textures are made in batches, so if the PC is turned off or the game is closed before the end, the next start of the game carries on from there instead of starting over. It runs at a lower priority, so the game stays smooth.

**How to install**: download *Source code (zip)* below, unzip it and double-click `Install Dragon Quest IX.bat`, then choose your own ROM (USA or European). **Already on v31.x or later?** The game offers the update when it starts (or Help > Check for updates): your saves and settings are kept.

**Not included, on purpose**: no ROM, no game executable and no data from the game. Everything is built on your PC from the ROM you own.

**Playing with friends**: everyone needs the same version, so all of you update to v35.
