en = Tag mode, visiting other worlds and inviting friends (Pavo) need DS systems close to each other. This lets friends anywhere play those parts together, up to 4 players.\n\nHow: one of you hosts (Wireless > Play with friends far away > Host), the others join with the code the host's game shows. When everyone is in, the host presses Start the game. All the games restart together, each from its own save, and from then on every PC runs every player's DS: yours in the window, your friends' unseen. Only the buttons travel between the PCs, so the DSes really are side by side - on every PC at once.\n\nWhat to expect:\n- Save your adventure before hosting or joining: the game restarts.\n- Everyone needs the same version of this game.\n- Buttons react a little later than usual (the input delay, a few frames, depending on the distance).\n- If someone's PC is slow, everyone waits for it while your DSes are talking wirelessly.\n- The built-in Wi-Fi works as usual (DQVC, the downloads), with the host's files for everyone. Other online servers are off during a session.\n- Your game saves to your own save as always. Leaving (or closing the game) switches your DS off for the others.\n\nGetting in: the code works on any internet - it connects through a small relay on the internet when the host's router doesn't let friends in directly (apartment and mobile internet, for example). Where the router does, the host's game also shows an address that connects directly, with a little less delay. Windows may ask whether to allow the game on networks: allow it.
de = Der Tag-Modus, Besuche in anderen Welten und Einladungen von Freunden brauchen DS-Systeme nah beieinander. Hiermit können Freunde überall diese Teile zusammen spielen, bis zu 4 Spieler.\n\nSo geht's: einer von euch eröffnet (Drahtlos > Mit Freunden in der Ferne spielen > Gastgeber), die anderen treten mit dem Code bei, den das Spiel des Gastgebers zeigt. Wenn alle da sind, drückt der Gastgeber auf Spiel starten. Alle Spiele starten zusammen neu, jedes von seinem eigenen Spielstand, und ab dann führt jeder PC den DS jedes Spielers aus: deinen im Fenster, die deiner Freunde unsichtbar. Nur die Knöpfe gehen zwischen den PCs hin und her, die DS stehen also wirklich nebeneinander, auf jedem PC zugleich.\n\nWas dich erwartet:\n- Speichere dein Abenteuer, bevor du eröffnest oder beitrittst: das Spiel startet neu.\n- Alle brauchen dieselbe Version dieses Spiels.\n- Die Knöpfe reagieren etwas später als sonst (die Eingabeverzögerung, ein paar Bilder, je nach Entfernung).\n- Ist der PC von jemandem langsam, warten alle auf ihn, während eure DS drahtlos miteinander sprechen.\n- Das eingebaute WLAN funktioniert wie gewohnt (DQVC, Downloads), mit den Dateien des Gastgebers für alle. Andere Online-Server sind während einer Sitzung aus.\n- Dein Spiel speichert wie immer in deinen eigenen Spielstand. Verlassen (oder das Spiel schließen) schaltet deinen DS für die anderen aus.\n\nVerbindung: der Code funktioniert mit jedem Internet: er läuft über ein kleines Relais im Internet, wenn der Router des Gastgebers Freunde nicht direkt hereinlässt (zum Beispiel in Wohnungen oder mobilem Internet). Wo der Router es erlaubt, zeigt das Spiel des Gastgebers auch eine Adresse, die direkt verbindet, mit etwas weniger Verzögerung. Windows fragt vielleicht, ob das Spiel in Netzwerken erlaubt sein soll: erlaube es.
