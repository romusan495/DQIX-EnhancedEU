en = Tag mode, visiting other worlds and inviting friends (Pavo) need DS systems close to each other. This lets friends anywhere play those parts together, up to 4 players.\n\nHow: one of you hosts (Wireless > Play with friends far away > Host), the others join with the code the host's game shows. When everyone is in, the host presses Start the game. All the games restart together, each from its own save, and from then on every PC runs every player's DS: yours in the window, your friends' unseen. Only the buttons travel between the PCs, so the DSes really are side by side - on every PC at once.\n\nWhat to expect:\n- Save your adventure before hosting or joining: the game restarts.\n- Everyone needs the same version of this game.\n- Buttons react a little later than usual (the input delay, a few frames, depending on the distance).\n- If someone's PC is slow, everyone waits for it while your DSes are talking wirelessly.\n- The built-in Wi-Fi works as usual (DQVC, the downloads), with the host's files for everyone. Other online servers are off during a session.\n- Your game saves to your own save as always. Leaving (or closing the game) switches your DS off for the others.\n\nGetting in: the code works on any internet - it connects through a small relay on the internet when the host's router doesn't let friends in directly (apartment and mobile internet, for example). Where the router does, the host's game also shows an address that connects directly, with a little less delay. Windows may ask whether to allow the game on networks: allow it.
fr = Le mode Contact, les visites dans d'autres mondes et les invitations d'amis demandent des DS proches les unes des autres. Ceci permet à des amis où qu'ils soient de jouer ces parties ensemble, jusqu'à 4 joueurs.\n\nComment : l'un de vous héberge (Sans fil > Jouer avec des amis à distance > Héberger), les autres rejoignent avec le code affiché par le jeu de l'hôte. Quand tout le monde est là, l'hôte appuie sur Commencer la partie. Tous les jeux redémarrent ensemble, chacun depuis sa propre sauvegarde, et à partir de là chaque PC fait tourner la DS de chaque joueur : la vôtre dans la fenêtre, celles de vos amis sans être vues. Seuls les boutons circulent entre les PC, donc les DS sont vraiment côte à côte, sur chaque PC à la fois.\n\nÀ quoi s'attendre :\n- Sauvegardez votre aventure avant d'héberger ou de rejoindre : le jeu redémarre.\n- Tout le monde doit avoir la même version de ce jeu.\n- Les boutons réagissent un peu plus tard que d'habitude (le délai d'entrée, quelques images, selon la distance).\n- Si le PC de quelqu'un est lent, tout le monde l'attend pendant que vos DS communiquent sans fil.\n- Le Wi-Fi intégré fonctionne comme d'habitude (DQVC, téléchargements), avec les fichiers de l'hôte pour tous. Les autres serveurs en ligne sont coupés pendant une session.\n- Votre jeu sauvegarde dans votre propre sauvegarde, comme toujours. Partir (ou fermer le jeu) éteint votre DS pour les autres.\n\nSe connecter : le code fonctionne sur n'importe quelle connexion : il passe par un petit relais sur Internet quand le routeur de l'hôte ne laisse pas entrer les amis directement (en appartement ou en 4G/5G, par exemple). Quand le routeur le permet, le jeu de l'hôte affiche aussi une adresse qui se connecte directement, avec un peu moins de délai. Windows peut demander s'il faut autoriser le jeu sur les réseaux : autorisez-le.
